# سررسید (Sarresid) - مدیریت هوشمند چک و اقساط

اپلیکیشن جامع و کاربردی اندروید برای مدیریت چک‌های صیادی، اقساط وام‌های بانکی، تقویم شمسی و یادآوری دقیق سررسیدها.

## 📱 امکانات کلیدی

- **مدیریت چک‌های صیادی:** ثبت، ویرایش، استعلام و فیلتر چک‌های دریافتی و پرداختی با قابلیت بایگانی و گزارش وضعیت
- **مدیریت وام و اقساط:** محاسبه خودکار جدول اقساط، ثبت تاریخ سررسید و پیگیری اقساط پرداخت شده / مانده
- **تقویم شمسی (جلالی):** نمایش رویدادها و سررسیدهای مالی به تفکیک روز و ماه در تقویم فارسی
- **یادآور و آلارم هوشمند:** تنظیم نوتیفیکیشن و یادآوری اختصاصی قبل از موعد سررسید
- **تراز مالی و داشبورد تحلیلی:** مشاهده مجموع بدهی‌ها، بستانکاری‌ها و جریان نقدی ماهانه
- **راهنمای جامع بانک‌ها:** پیش‌شماره کارت‌ها و دسترسی به درگاه‌های استعلام چک صیادی بانک‌های کشور
- **نسخه پریمیوم:** پلن طلایی برای امکانات پیشرفته و ثبت نامحدود

## 🛠️ فناوری‌های مورد استفاده

- **زبان:** Kotlin
- **رابط کاربری:** Jetpack Compose & Material Design 3
- **پایگاه داده محلی:** Room Database (با KSP)
- **معماری:** MVVM با StateFlow و Coroutines
- **پشتیبانی سیستم‌عامل:** Android 8.0 (API 26) و بالاتر

## 🚀 نحوه اجرا در Android Studio

1. این مخزن را Clone کنید:
   ```bash
   git clone https://github.com/sajjadsm90/sarresid.git
   ```
2. پروژه را در **Android Studio** باز کنید (`Open`).
3. منتظر اتمام Gradle Sync بمانید.
4. پروژه را روی شبیه‌ساز یا دستگاه متصل اجرا کنید.
